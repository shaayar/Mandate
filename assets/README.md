# Mandate Brand Assets v1.0

**Direction:** The Authority Gate  
**Descriptor:** Policy enforcement for AI agents.  
**Brand principle:** Give agents the authority they need, not unrestricted power.

## Contents
- `logos/`: editable SVG masters and PNG logo variants
- `icons/`: 16, 32, 64, 128, 256, and 512 px icons plus favicon
- `banners/`: GitHub/social preview image, 1280 × 640
- `guidelines/`: quick brand guide and palette swatches

## Palette
| Token | Hex | Use |
|---|---|---|
| Midnight Navy | `#0B1F26` | Primary dark background |
| Deep Teal | `#0E8F80` | Secondary gate segment |
| Electric Teal | `#14DBA6` | Accent |
| Off White | `#F8FAFC` | Light background / dark-mode text |
| Ink | `#10252B` | Main text |
| Muted Slate | `#5F747B` | Secondary text |

## Typography
Preferred: Space Grotesk for headings and Inter for body/UI. SVGs use common sans-serif fallbacks. PNGs use a locally available sans-serif font.

## Usage
- Use the dark logo on light backgrounds and the light logo on dark backgrounds.
- Use the square icon for package icons, avatars, and favicons.
- Preserve proportions, colors, and clear space. Do not stretch, skew, or add effects.
- For tiny sizes, prefer the icon-only mark and test at its actual rendered size.

## Release note
This package finalizes the project's visual direction and first-party assets. Trademark clearance and package-name availability are separate checks and are not implied.
